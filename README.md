# 猫の去勢・避妊 最短予約日

動物病院で猫の去勢・避妊手術が「最短いつ取れたか」を、予約した人が
持ち寄る静的サイト。野良猫の保護・さくらねこ（TNR）活動を応援する。

47 都道府県を選べる。病院データと登録フォームがあるのは今は **青森県だけ** で、
他の県は「準備中」と出て登録ボタンは出ない。県は URL で指定できる
（`index.html?pref=青森県`）ので、県ごとのページとして共有できる。

## 県を増やす手順

1. `data/clinics.json` にその県の病院を足す（`"pref": "岩手県"` のように都道府県名を入れる）。
   これだけで一覧に出るが、登録はまだ受け付けない
2. フォームの「病院名」の選択肢にその県の病院を足す
   （`tools/create_form.gs` の `CLINICS` と、作成済みフォームの編集画面の両方）
3. `config.js` の `formPrefs` にその県を加える → 登録ボタンが出る

⚠️ 登録は病院名だけで照合している。別の県に同じ名前の病院（例: さくら動物病院）が
ある県を足すときは、フォームの選択肢を「病院名（市町村）」にするなどして区別すること。

## 構成（サーバー不要）

```
index.html         ページ本体（病院一覧 + 登録の表示）
config.js          運用で触るのはここだけ（フォーム URL、CSV URL）
data/clinics.json  病院の公開情報（名前・住所・電話・診療時間）
```

- 病院一覧は `data/clinics.json` から読む
- 登録は **Googleフォーム → 回答スプレッドシート → 「ウェブに公開」した CSV** を
  ブラウザが直接読む。サーバー側の処理は一切無い

## 運用サーバー

**GitHub Pages を推奨**（無料・HTTPS・独自ドメイン可・git push で更新）。

1. GitHub にリポジトリを作り、この内容を push する
2. Settings → Pages → Source を `main` / `/ (root)` にする
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で見える

代替:
- **Cloudflare Pages**: 同じく無料。独自ドメインを Cloudflare で管理しているならこちらが楽
- **Netlify**: 無料枠あり。フォームを Netlify Forms に置き換える道もあるが、
  月100件の上限があるので Google フォームのままでよい

避けるもの: VPS・レンタルサーバー。静的ファイル 3 つに月額と保守を払う理由が無い。

## Googleフォームの作り方

### 自動（推奨）: `tools/create_form.gs`

1. https://script.google.com/ で新しいプロジェクトを作り、`tools/create_form.gs` を全部貼る
2. `createForm` を実行し、Google アカウントの許可を出す
3. 実行ログの `formUrl` と `formClinicEntry` の行を `config.js` へ貼る
4. ログに出たスプレッドシートを開き、ファイル → 共有 → ウェブに公開 →
   「フォームの回答 1」/ CSV で公開。その URL を `config.js` の `sheetCsvUrl` へ

病院名はプルダウン（`clinics.json` と同じ 38 件 + その他）。自由入力だと
表記揺れでサイトの病院と一致しなくなるため。病院を足したら両方を直す。

### 手動

1. Google フォームを新規作成。設問はこの順で:
   1. 病院名（記述式、必須）
   2. 手術の種類（選択式: 去勢（オス）／避妊（メス））
   3. 電話した日（日付）
   4. 最短で取れた手術日（日付、必須）
   5. 備考（記述式、任意。「術前検査が別日」など）
2. 「回答」タブ → スプレッドシートを作成
3. そのスプレッドシートで **ファイル → 共有 → ウェブに公開**。
   対象を「フォームの回答 1」シート、形式を **CSV** にして公開。出た URL を
   `config.js` の `sheetCsvUrl` に入れる
4. フォームの「送信」→ リンクの URL を `config.js` の `formUrl` に入れる
5. （任意）病院名を事前入力させる: フォームの「⋮ → 事前入力した URL を取得」で
   病院名に何か入れて URL を作ると `entry.123456789=...` が含まれる。
   その `entry.123456789` を `formClinicEntry` に入れる

列の並びを変えたら `index.html` の `r[1]`〜`r[5]` も直す。

## いたずら・誤情報への備え

- 免責はページ冒頭に明記済み（善意の登録・最短の保証なし・登録日時を併記）
- 登録から `staleDays`（既定 90 日）を過ぎた物は「古い」と色を変えて出す
- 明らかなおかしい行はスプレッドシート側で行を消せば消える（サイト側の作業は不要）
- 荒れたら Google フォームの「ログインを必須にする」を有効にする

## 病院情報の更新

`data/clinics.json` を直して push する。出典と取得日は `source` に書く。
掲載の訂正・削除依頼が来たら該当行を消して push すればよい。
